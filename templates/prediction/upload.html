Required CSV Columns

The uploaded file must contain these columns:

  • Date
  • Iron_Ore_Price_USD_per_tonne
  • Steel_Production_Index
  • Demand_Index
  • Supply_Index
  • Freight_Cost_USD_per_tonne
  • Oil_Price_USD_per_barrel
  • USD_CNY_Exchange_Rate

Automatic Validation

Before retraining, the system checks:

  • Required columns
  • Minimum 30 records
  • Valid dates
  • Numeric market values
  • Dataset ordering
  • Model training compatibility

Automatic Model Retraining Workflow

1
Upload Admin uploads the new CSV dataset.
2
Validate The system checks columns, dates and numeric values.
3
Retrain Linear Regression, Decision Tree and Random Forest are trained.
4
Select Best Model The model with the lowest RMSE becomes the active model.
